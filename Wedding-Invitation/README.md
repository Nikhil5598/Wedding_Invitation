# Nivetha & Kishor Kumar Wedding Invitation

Digital wedding invitation website for Nivetha and Kishor Kumar. The page includes a countdown timer, event details, venue map, background music, and a responsive floral design that works well on mobile and desktop.

## Project Name

Nivetha & Kishor Kumar Wedding Invitation

## Description

A static wedding invitation website built with HTML, CSS, and JavaScript. It is designed to be shared online or uploaded to GitHub Pages, Netlify, or any static hosting platform.

## Features

- Countdown timer for the wedding day
- Couple name and ceremony details
- Embedded venue map
- Background music and decorative animation
- Responsive layout for phones and desktops

## Preview

Open `index.html` in a browser to view the invitation locally.

## Project Structure

```text
index.html
css/
js/
assets/
invitation/
```

## How to Use

1. Update the couple names, date, time, and venue in `index.html`.
2. Update the countdown logic in `js/script.js` if you want the timer to match a new date.
3. Replace images, music, and colors in `assets/` and `css/style.css` as needed.
4. Upload the files to GitHub and publish with GitHub Pages or another static host.
